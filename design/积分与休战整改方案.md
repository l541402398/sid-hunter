# S-ID：轻量玩法整改方案与积分来源

- 整理日期：2026-11-06。
- 代码基线：当前本地 `dev` 分支，提交 `efb18e3`。
- 文档用途：汇总本轮已确认的整改规则，供产品、开发、测试及运营讨论使用。
- 状态说明：本文描述整改目标，不代表代码已经实现；未确认的数值、概率和次数明确标注为“建议”或“待定”。
- 最新口径：生命归零后进入“休战状态”，仍可通过探索、答题、J互动、小游戏等获得积分及奖品，只停止存活分和对抗分。

## 一、整改背景与目标

现有玩法同时包含金币、积分、身份码、多种身份技能和多项NPC兑换，玩家理解成本较高。本轮整改将收益统一为积分，并将对抗简化为“一个技能、有限生命、使用后冷却”。

玩家的主要体验调整为：

> 探索箱子／柜子 → 直接获得积分或答题得分 → 每探索5个容器解锁一项NPC福利；途中可通过J互动、小游戏获得积分，并有机会随机获得实物奖品。

对抗作为另一条参与路径：玩家根据阵营使用“指认”或“刺杀”，对抗生命归零后进入休战状态，继续参与其他玩法。

## 二、项目现状与整改范围

| 模块 | 当前代码主要行为 | 本次整改目标 |
| --- | --- | --- |
| 收益体系 | 金币与积分分开，金币用于NPC兑换、转盘和猜拳等 | 合并为积分体系，积分用于累计排名，不作为消费货币 |
| 地图探索 | 每位玩家独立随机开出空箱、金币或答题；容器开启后登记记录 | 保留独立随机和一次开启规则，金币奖励改为积分，增加实物抽奖机会 |
| NPC | 六类金币兑换，转盘单独计次 | 按探索数量逐档解锁福利，免费领取；积分礼包、转盘均可产出积分 |
| 对抗 | 好人调查／指认，坏人公开身份码／击杀，以三段身份码控制进度 | 每个阵营只有一个技能，以可配置的对抗生命控制参与资格 |
| 阵营与生命 | 本地加入逻辑仍为首位坏人、其余好人；好坏初始生命不同 | 随机分配好人、坏人，比例4∶1，双方默认3格生命 |
| 技能资源 | 可储存2次机会，恢复周期统一管理 | 初始1次、最多1次；好人30分钟CD，坏人20分钟CD |
| 生命归零后的参与 | 原幽灵状态限制探索、答题、房间进入及部分小游戏，停止得分 | 改为休战状态，允许非对抗玩法及其积分奖励 |
| 基础参与分 | 首次搜索＋5分、首次小游戏＋5分 | 两项均取消，避免与新得分规则叠加 |
| 对抗得分 | 正确指认＋10、公开好人身份码＋2、击杀好人＋5 | 正确指认＋10、正确刺杀＋3；不额外奖励最后一击 |

本轮继续沿用已取消物品背包、使用和买卖功能的方向，不重新引入实体道具管理。

## 三、统一积分体系

1. 取消独立金币余额，原金币产出入口按新规则直接发放积分。
2. 积分持续累计，展示今日积分与活动累计积分，不每日清零。
3. NPC福利和转盘不消耗积分，避免玩家为了领取功能而损失排名分。
4. 每日重置探索机会、福利领取次数、互动和小游戏渠道额度等每日记录。
5. 每日总积分不设统一上限；不同来源分别受容器数量、渠道额度、技能CD等条件约束。
6. 各类积分都只在服务端确认行为有效后入账，失败、重复请求不能重复加分。
7. 历史积分保留。既有金币余额如何处理需在上线前确认，不能将未确认的兑换比例直接用于历史数据。

## 四、地图探索与答题

### 4.1 容器开启规则

- 每个箱子／柜子的内容对每位玩家独立随机，不因其他玩家已经开启而耗尽普通奖励。
- 同一玩家对同一容器每日只能开启一次；次日新局恢复探索机会。
- 同一天刷新、重登或重新进入地图，不恢复已开启容器的机会。
- 开启结果可以为空、直接积分或答题；普通结果的随机性与实物奖品库存分别处理。
- 关闭面板、重复点击不能重新抽取结果；未完成题目允许继续，已提交题目不能重复获得奖励。
- 探索积分和答题积分均不设置额外每日得分上限，但不能重复开启同一容器或重复提交获奖。

### 4.2 探索结果与建议参数

以下概率与分值是用于试玩的建议，尚未最终确认。

| 探索结果 | 建议概率 | 建议积分 | 说明 |
| --- | ---: | ---: | --- |
| 空箱 | 5% | 0分 | 不扣分，计入有效探索数量 |
| 直接获得积分 | 15% | ＋1分 | 立即入账 |
| 触发答题 | 80% | 答对＋2分，答错0分 | 题目只允许一次有效提交 |

一次开箱的普通结果只能属于以上一种，不同时叠加“直接积分”和“答题积分”。实物奖品作为额外事件独立判定，不占上述概率之和。

### 4.3 答题与探索计数

- 优先使用短题干的单选、判断题，降低答题负担；题库需同步清理旧身份码、旧技能等失效内容。
- 答题前明确展示答对可获得的积分，答错不扣分。
- 同一题目提交合法答案后即完成本次结算，不能重复试答案领奖。
- 建议空箱、直接积分箱立即计入探索数量；答题箱在提交有效答案后计数，答错也算，避免只打开弹窗就刷福利进度。
- 上述答题箱计数时机为建议口径，需在开发前最终确认。

## 五、J趣味互动与小游戏

### 5.1 J互动得分

- J继续用于趣味互动，不扣对抗生命，不消耗指认／刺杀机会，不触发对抗受击保护。
- 有效命中其他玩家后，随机判定是否获得积分，不保证每次命中都得分。
- 积分由系统新增给操作者，被互动者不扣已有积分。
- 单一目标最多贡献2积分；建议统计口径为“同一操作者→同一目标，每日累计最多2分”，该周期口径需最终确认。
- 建议每次触发奖励＋1分，本渠道每日最多10分；单次分值、每日上限和触发概率尚待最终确认。
- 仅对有效在线真人目标触发得分，NPC、离线账号和无效命中不产分；对抗中和休战中的玩家均可参与正常J互动。
- 实物抽奖有独立的有效触发次数或冷却限制，不能因为积分奖励随机、未触发或达到上限，就无限重复互锤抽奖。

### 5.2 小游戏得分

- 开放已具备实现基础的小游戏，建议第一版优先猜拳，其他小游戏按现有实现成熟度逐步开放。
- 正常完成一局且获胜，由系统新增积分，输家不扣分，不再要求下注金币。
- 失败、平局、取消或超时均为0分；取消或超时产生的结果不作为正常胜局发放积分。
- 所有小游戏共用每日得分额度，避免切换游戏重复领取各自上限。
- 建议每胜一局＋2分，小游戏合计每日最多10分；具体分值、上限和同一对手可计分次数待定。
- 休战玩家可以正常参与，并沿用休战前已经消耗的渠道额度。

## 六、NPC福利与转盘

### 6.1 探索进度解锁

1. 每探索5个不同容器，依次解锁一项福利：5个解锁第1项，10个解锁第2项，后续类推。
2. 解锁不等于领取，玩家可以自行选择领取时机。
3. 已解锁但未领取的前置福利继续保留，不因解锁后续档位而消失。
4. 领取不扣积分，也不扣探索数量；每项每日领取一次，所有楼层NPC共享进度和次数。
5. 休战后仍可领取符合条件的福利，不重新计算已领取次数。
6. 每5箱解锁福利本身不加分，只有实际领取积分礼包等明确奖励时才入账。

### 6.2 福利内容

| 福利 | 本轮处理口径 |
| --- | --- |
| 积分礼包 | 纳入积分来源；达到档位后免费领取，分值待定，建议＋10分、每日一次 |
| 公开随机玩家的一条隐藏属性 | 保留信息效果，改为按档位解锁后领取 |
| 公开指定玩家的一条隐藏属性 | 保留信息效果，改为按档位解锁后领取 |
| 隐藏自己的一条已公开属性 | 保留信息效果，仅影响人物公开档案，不改变真实属性 |
| 隐藏指定匿名坏人卡上的一条已公布线索 | 保留一条线索的隐藏效果，不隐藏整张卡，不提供匿名卡与真人的对应关系 |
| 隐藏自己最近公开的一段身份码 | 随身份码机制取消，不改成回血福利 |

积分礼包及四类信息福利的具体档位顺序待定。对目标无效、没有可公开／隐藏内容等情况，不消耗领取次数。

人物公开档案与匿名坏人池继续保持独立记录；隐藏展示不改变真实属性，也不能撤回其他玩家已经掌握的信息。隐藏线索是否限时、何时恢复仍需明确。

### 6.3 转盘积分

- 转盘产出改为随机积分，作为独立积分来源保留。
- 不再收取金币，也不消耗已有积分，通过每日次数或探索解锁条件控制参与。
- 所有楼层NPC共用同一玩家的转盘次数，休战前后共用记录。
- 每日次数、是否需要探索档位解锁、各积分档位及概率待定；可考虑沿用现有“每日最多3次”的次数规模。
- 一次转盘结果只能结算一次，重新打开面板不能重抽或重复领奖。

## 七、简化对抗规则

### 7.1 阵营与初始状态

- 好人∶坏人＝4∶1，随机分配，不通过固定加入顺序暴露身份。
- 所有玩家默认拥有3格对抗生命，初始生命数量由管理页配置。
- 每位玩家只有一个身份技能：好人为“指认”，坏人为“刺杀”。
- 取消调查属性技能、身份码逐段公开和单独击杀操作；信息获取转由系统线索和NPC福利承担。
- 每人进入当日游戏时有1次技能机会，最多持有1次，等待再久也不累计。

### 7.2 技能效果与计分

| 操作者 | 操作目标 | 生命变化 | 操作者积分 | 有效操作后CD |
| --- | --- | --- | ---: | --- |
| 好人使用指认 | 坏人 | 目标扣1格生命 | ＋10分 | 30分钟 |
| 好人使用指认 | 好人 | 操作者自己扣1格，目标不扣血 | 0分 | 30分钟 |
| 坏人使用刺杀 | 好人 | 目标扣1格生命 | ＋3分 | 20分钟 |
| 坏人使用刺杀 | 坏人 | 双方生命不变 | 0分 | 20分钟 |

- 正确、错误的有效操作都消耗机会，并进入完整CD。
- 生命扣至0时立即进入休战状态；最后一击只发本次正常的10分或3分，不叠加旧击杀奖励。
- 不因失败扣已有积分；误指认的代价仅为自己的生命和本次技能机会。
- 离线仍计算CD；CD结束恢复到1次，不能累计多次。

### 7.3 每日同目标限制与无效操作

- 同一操作者每天对同一目标只能执行一次有效指认或刺杀，无论结果正确还是错误。
- 此记录按“操作者→目标”保存，不因对方对自己使用技能而占用自己的次数。
- 自选、目标休战、目标处于保护期、当天已有效操作过该目标等无效请求，不扣生命、不加分、不消耗机会、不占用新的操作记录，也不进入CD。
- 刷新、重登或服务重启，不恢复生命、不补发次数、不清除当日同目标记录。

### 7.4 受击保护与保护罩

- 受到他人技能伤害后，默认获得5分钟受击保护，保护时长由管理页配置。
- 保护期内不能再次成为指认／刺杀的有效目标，角色显示保护罩。
- 保护不影响本人正常使用技能；误指认造成的自身扣血不触发保护，也不能被已有保护抵消。
- J互动不扣生命，不触发、消耗或延长这项保护。
- 若本次扣血使生命归零，立即进入休战，不再靠保护保留对抗资格。
- 保护罩不区分阵营，公共展示不能据此识别好坏人。

### 7.5 信息展示

- 技能名称只对本人展示；自己的操作结果和得分可以私下查看。
- 公共提示只展示生命变化，不展示操作者、技能类型及即时得分。
- 玩家资料、受击记录、公共日志、情报联动区等入口统一遵守上述边界，不能从其他展示入口泄露攻击者阵营。
- 保留系统匿名坏人线索与NPC信息获取，避免取消调查技能后，好人只能盲猜。

## 八、休战状态

玩家状态统一展示为“对抗中／休战中”。对抗生命归零后进入休战，不再使用“出局”“淘汰”描述其游戏参与资格。

| 行为或收益 | 对抗中 | 休战中 |
| --- | --- | --- |
| 地图探索、答题及其积分 | 可以 | 可以 |
| J趣味互动及其积分 | 可以 | 可以 |
| 小游戏及其积分 | 可以 | 可以 |
| 领取已解锁NPC福利 | 按条件领取 | 按条件领取 |
| 转盘积分 | 按次数及条件参与 | 按次数及条件参与 |
| 获得实物奖品 | 可以 | 可以，共享活动期间一次上限 |
| 获得存活分 | 可以 | 停止 |
| 使用指认／刺杀、获得对抗分 | 可以 | 停止 |
| 成为指认／刺杀目标 | 可以 | 不可以 |

- 已得积分全部保留，所有每日额度、探索记录、福利及转盘次数继续沿用，不因休战重置。
- 休战玩家沿用正常移动、碰撞、房间进入和探索条件，不获得穿墙刷箱优势；可以用半透明外观标识状态。
- 原幽灵禁入房间、禁止搜索／答题／小游戏、统一禁止加分等逻辑需同步调整，不能只替换界面名称。
- NPC暂不提供恢复生命或恢复当日对抗资格的福利。
- 次日新局重新分配阵营、恢复初始生命和1次技能机会。

建议提示文案：

> 你已进入休战状态，本日不再参与对抗。仍可探索、答题、趣味互动和参加小游戏，继续赢取积分与奖品！

## 九、实物奖品

1. 实物奖品可在探索地图、与玩家互动时随机获得，首批明确覆盖有效开箱与J命中；其他渠道是否接入另行配置。
2. 实物奖励与积分独立判定，一次行为可以同时获得积分和实物，也可以只获得其中一种。
3. 活动期间每位员工最多获得一次实物奖品，所有渠道共用中奖资格和全服奖品库存。
4. 中奖后仍正常获得积分，不再参与后续实物抽取；进入休战不刷新中奖资格。
5. 奖品直接锁定给触发玩家，用掉落动画表现，无需捡取和争抢。
6. 实物中奖本身不额外加分；同次行为满足积分条件时，正常发放该行为积分。
7. 建议按天或时段分批投放，避免库存过早耗尽；奖品品类、数量、各渠道概率和触发频率待定。
8. 随机开箱普通结果对每位玩家独立，但实物库存全服共享；并发中奖不能超发，同一人不能重复领取。

### 10.1 已确认的零分与取消规则

- 空箱、答错、误指认、刺杀坏人、无效技能操作，以及小游戏失败、平局、取消或超时，均为0分，不扣已有积分。
- 对抗最后一击只获得本次正常的10分或3分，不叠加旧击杀奖励。
- 实物中奖、每5箱解锁福利本身不额外加分。
- 取消“首次搜索＋5分、首次小游戏＋5分”，不与新积分来源叠加。
- 原公开身份码＋2分、单独击杀＋5分随对应玩法取消，不作为独立积分来源保留。
- NPC信息类福利只产生信息效果，不额外加分；积分礼包按礼包本身的规则发放。
- 有效行为完成后即使客户端重复提交或重连，也只能获得一次积分。

### 10.2 积分统计口径

- 今日积分＝当日各来源实际获得积分之和。
- 活动累计积分＝活动各日已计入成绩的积分累计。
- 每日总积分不设统一上限。J和小游戏受各自渠道额度限制，探索受容器数量限制，NPC与转盘受领取／参与次数限制，对抗受CD和每日同目标一次限制。
- NPC积分礼包、转盘积分均正式列入来源统计和本人明细。
- 休战仅停止存活分和对抗分，不影响其他渠道的正常积分。
- 实物奖品单独记录，不折算积分。

### 11.2 存档与一致性

- 员工账号作为正式活动身份标识；每日记录按账号与北京时间日期保存，实物中奖记录按账号与整个活动保存。
- 同日切场不能意外重复发放正式活动的每日额度、福利和实物资格；测试场与正式场的隔离方式需在实施时明确。
- 积分、对抗生命、休战状态、技能CD、保护结束时间、每日目标记录、探索进度、福利次数、转盘次数及奖品资格均需保存。
- 重启、刷新和重登不能补发机会、恢复生命、重抽奖励或重复领取；离线正常计算技能CD。
- 伤害、保护、转入休战、积分、技能消耗及同目标记录必须一致结算，不能出现已扣血但未记次数等中间结果。
- 积分奖励和实物库存结算需防止重复请求及并发超发；存档失败时不能先向玩家宣布领取成功。

### 11.3 主要验收场景

1. 同一容器对不同玩家独立随机，对同一玩家不能重复开启或通过重登重抽。
2. 正确、错误和无效技能操作分别符合伤害、计分、机会和CD规则。
3. 5分钟保护期间他人技能不能再次扣血；误指认自身扣血仍生效，J不影响对抗生命。
4. 同一操作者每日不能第二次有效操作同一目标，重启后限制仍在。
5. 最后一格生命扣完进入休战，无额外击杀积分，无回血福利或当日自动复活。
6. 休战前后的探索、答题、J、小游戏、NPC礼包及转盘积分均可正常获得，日额度不刷新；存活分和对抗分停止。
7. 休战玩家可按正常条件进入房间和探索，不沿用旧幽灵的穿墙优势或禁入限制。
8. 取消首搜、首游及旧身份码／击杀奖励，积分明细不重复叠加。
9. NPC按5箱一档解锁，所有NPC共用进度和领取次数；礼包与转盘积分纳入统计。
10. 实物奖品各渠道共用活动期间一次上限和库存，重复请求、跨渠道及并发情况下不重复中奖、不超发。
11. 公共日志、资料和受击记录不泄露操作者、技能类型及即时得分，保护罩不泄露阵营。
